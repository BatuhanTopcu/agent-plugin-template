# Inspect a change

1. Read project instructions and identify the desired behavior.
2. Inspect the changed files and trace affected callers.
3. Follow the [review checklist](references/checklist.md).
4. Run the project's existing relevant checks when execution is authorized.
5. Report concrete findings, verification results, and remaining uncertainty.

Use a reviewer subagent when available. The same checklist applies when reviewing in the main conversation.
